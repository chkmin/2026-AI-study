## <AI 스터디 4주차 WIL>

### 이번주 스터디 목표
AI 정규 스터디의 4주차인 만큼 이제 점점 더 어려워지니 이번에는 코드 문법 위주 보다는 천천히 전체적인 틀을 보며 코드가 돌아가는 원리를 파악하며 실습과 과제를 해봐야겠다!

### 오늘의 키워드
로지스틱 회귀, 시그모이드 함수, 손실함수, 경사하강법, 확률적 경사하강법

**1. 로지스틱 회귀**
- 로지스틱 회귀: 이름만큼은 회귀지만 엄연한 분류 모델로서 여러 변수를 고려한 선형방정식을 학습한다. 이는 다중회귀의 선형방적식을 다룬다.

- z를 0~1 값으로 만들기 위해 음의 무한대: 0에 수렴, 양의 무한대: 1에 수렴


**2. 시그모이드 함수**
- 시그모이드 함수를 이용해 z를 0~1 값으로 조정해줌


**3.손실 함수**
- 손실함수: 실제 데이터 값과 예측 모델의 값의 차이를 나타내는 함수

- 모델이 어느정도로 부정확한지 판단하는 함수기 때문에 손실함수값이 작을수록 좋음

- 미분을 이용해 손실함수의 최저값을 찾음(단, 지역최소점 주의)

**4.경사 하강법**
- 경사하강법: 경사를 따라서 내려가며 훈련하는 방법

- 이는 새로운 데이터에 대해서 추가적으로 훈련 시키는 점진적 학습을 사용함

- 경사가 없는 최저점을 찾아서 이동

**5.확률적 경사 하강법**
- 경사하강법에서 전체 훈련 데이터가 아닌 일부만 골라서 사용함

- 에포크: 전체의 데이터셋을 전부 사용 후 다시 전체 데이터셋을 가지고 경사하강법을 진행하는 과정

- 미니배치 경사하강법: 샘플 하나씩이 아닌 여러개씩 뽑아서 경사를 내려가며 훈련하는 방법


### 느낀점
